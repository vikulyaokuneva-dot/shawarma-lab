Здесь лежат изображения товаров и hero-блока:

| Файл                   | Где используется      | Пропорции |
| ---------------------- | --------------------- | --------- |
| `hero-shawarma.jpg`    | Hero (главный экран)   | 4:5       |
| `classic-chicken.jpg`  | карточка Classic Chicken | 4:3    |
| `spicy-beef.jpg`       | карточка Spicy Beef   | 4:3       |

## Замена на реальные фотографии

Сейчас изображения — процедурные плейсхолдеры (см. `scripts/generate-images.mjs`).
Чтобы подставить настоящую food-фотографию:

1. Сохраните фото с **тем же именем** и тем же разрешением (или крупнее):
   `classic-chicken.jpg`, `spicy-beef.jpg`, `cheese-chicken.jpg`, `hero-shawarma.jpg`.
2. Перезагрузите страницу — код менять не нужно, пути берутся из `data/products.ts`.

Рекомендации по съёмке: тёмный фон, крупный план, видна начинка
(мясо, овощи, соус), без текста, логотипов и watermark.
